## ADDED Requirements

### Requirement: json5 模块 spec 提供中文 mirror 文档

`openspec/specs/json5/spec.zh.md` SHALL fully mirror `spec.md` in Simplified Chinese with the same preservation rules as the json4 documentation requirement.

#### Scenario: json5 mirror exists

- **WHEN** the repository is checked out
- **THEN** `openspec/specs/json5/spec.zh.md` SHALL exist
- **AND** it SHALL cover module layout, parse sortKeys, format AST/triplet, and perf requirements
